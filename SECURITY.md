# Security policy

## Reporting a vulnerability

Please **do not disclose vulnerabilities in public GitHub issues, discussions, or pull requests**.

Report security vulnerabilities privately using [GitHub's vulnerability reporting for this repository](https://github.com/dceoy/gha-for-devops/security/advisories/new). Include the affected workflow or file, a minimal reproduction, expected impact, and any suggested mitigation.

If the private-reporting option is unavailable, request an alternate private reporting channel from the maintainer without publishing exploit details.

## Scope

This repository distributes reusable GitHub Actions workflows and related scripts. Reports concerning GitHub token permissions, workflow injection, credentials exposure, and supply-chain integrity are in scope.

For vulnerabilities in third-party dependencies or actions, also notify the upstream maintainer through their security-reporting channel.

Security fixes are assessed according to severity, exploitability, and affected use cases; no fixed response or remediation timeline is promised.
